Что бот берёт в обработку, а что отсеивает. Пустое поле = общий дефолт. Оранжевая полоска слева = вы переопределили дефолт. Применяется со следующего цикла охоты.

3. Стек
Исключить, если в заголовке изменено сбросить

Обычные слова — границы слов учитываются автоматически («java» не заденет «javascript»).

java php angular wordpress qa
в raw-режиме каждый паттерн проверяется на лету; кривой regex не даст сохранить
Правило «X без Y»

Отсеивать вакансии со стеком X, если рядом нет Y.

Блокировать если в вакансии нет
java spring .net python golang

Заголовок чистый («Frontend Developer»), а в описании вылезает платформа, с которой не работаешь. Проверяется по полному тексту, отдельный список от заголовочного.

blazor mendix outsystems low-code wordpress drupal magento sharepoint
4. Локация и гибрид
🏠 Домашний город: Wrocław (алиасы: wrocław, wroclaw) · принимаем: remote, zdalnie + домашний город.
Берётся из профиля кандидата — менять там, здесь не дублируется.

Ловит «remote» в шапке + «3 дня в офисе в Кракове» в тексте.

Вакансия с «1 день в неделю или реже» в польском городе не отсеивается. Чаще 1 дня/неделю, частота не указана или город за границей — отсев как обычно.
